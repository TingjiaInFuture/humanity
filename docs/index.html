01

正在发生什么

这份宪章不是写给未来的。

它回应的是已经开始的变化。下面这些事此刻正在发生——每一条都可以被检验，也可以被反驳。

01

机器开始胜任一般性脑力劳动。

读、写、改代码、做分析、翻译——过去需要多年训练才能做的工作，软件已经能完成相当部分，而且还在快速变好。

证据：METR：可完成任务时长约每 7 个月翻倍（2025-03） · Stanford AI Index 2026：SWE-bench Verified 一年内 60% → 接近满分

02

认知产出的成本在快速下降。

同等质量的文字、代码与分析，单价正以数量级的速度变便宜。技能一旦廉价，就换不回从前的生活。

证据：Stanford AI Index 2025：GPT-3.5 水平推理成本两年下降超 280 倍（$20 → $0.07 / 百万 token）

03

「劳动换生存」的前提在被侵蚀。

社保、医保、养老金、职业身份——许多制度都建立在「人靠劳动换取收入」之上。这条契约没有被废除，但正在松动。

证据：IMF：全球约 40% 岗位暴露于 AI（2024-01） · Stanford（2026-08 修订）：22–25 岁 AI 暴露职业就业较本应达到的趋势低约 19%，总量失业尚未出现

04

技术以月迭代，制度以年修订。

两边的时间差还在拉大。时间差里发生什么，取决于现在开始的公共讨论。

证据：Stanford AI Index 2026 年度主题：能力增长与度量、治理能力之间的鸿沟在扩大

05

结局还没有写定。

普遍富裕、极端分化、新的等级社会，都还是可能的方向，不是注定的剧本。正因为未定，讨论才有分量。

03

候选原则

第一版只有五条，先从最要紧的说起。

01

生存不以经济价值为条件。

一个人不应仅因无法与机器竞争而失去基本生存与尊严。

02

自动化成果应广泛惠及社会。

怎么分可以慢慢争，但不该默认都归少数人。

03

人保留对文明目标的参与权。

AI 可以帮忙找办法，但文明往哪走，不能只由几家机构或一套系统说了算。

04

每个人拥有认知与选择自由。

有权知道、有权说不要、有权选择自己和技术相处的方式。

05

宪章本身必须可以被公众修改。

谁发起的谁说了不算，写完了也不算完。每一次修改都公开留痕。

04

发起讨论

有一个问题，想听听更多人怎么说。

写下你的问题和背景——无需注册即可提交。提交后会生成一个公开的 GitHub 页面，任何人都能看到；在 GitHub 上回复需要 GitHub 账号。

05

提出修改

想改哪里，选哪里。

下拉框里选好位置，原文会自动填好，你只管写新的内容。提案公开后，大家一起看、一起定。

06

治理方式

规则是如何被书写的。

修改这份宪章的机制本身，也接受审视。四件事写在明处：

01

每个提案都有公开页面。

在网站提交后，后端先创建 GitHub Issue——没有黑箱，任何人都能看到并回复。

02

机器只做精确匹配。

只有当你选的原文在最新版宪章中恰好出现一次，后端才自动建分支和 PR；找不到或有多处匹配，就停在 Issue 等人处理。自动化不「理解」模糊请求。

03

永不自动合并。

是否采纳由公开审议决定。目前合并按钮在维护者手里——这是已知的中心化点，我们把它写在这里，而不是假装它不存在。

04

已知局限。

还没有身份与反滥用机制，限流只靠哈希 IP；社区变大后应迁移到专用 GitHub App 与更强的身份方案。v0.2 有意不提前建设。

07

公开记录

谁提了什么、改了什么，都查得到。

这里是最近的动态。更早的讨论和每一次修改都完整保留，随时可查。
