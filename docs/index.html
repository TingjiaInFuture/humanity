OPEN DRAFT · v0.2

当机器比人更会思考，
人仍应是文明的目的。

我们不声称代表全人类。我们只建立一个人人都能读、质疑、提出议题和申请修改的公开起点。

发起议题申请修改

无需 GitHub 账号。你的提交会由后端同步到公开 GitHub 记录。

01

候选原则

第一版只保留最少的共同问题。

01

生存不以经济价值为条件。

一个人不应仅因无法与机器竞争而失去基本生存与尊严。

02

自动化成果应广泛惠及社会。

具体分配方式可以争论，但极端集中不应成为默认结局。

03

人保留对文明目标的参与权。

AI 可以帮助寻找手段，但重大价值目标不能只由少数机构或自动系统决定。

04

每个人拥有认知与选择自由。

包括知情、拒绝隐秘操控，以及选择不同技术生活方式的权利。

05

宪章本身必须可以被公众修改。

发起人不是最终解释者。每次重要变化都应留下可公开追溯的记录。

02

发起议题

把一个值得共同讨论的问题放到桌面上。

提交成功后，后端会自动在 GitHub Discussions 创建公开讨论。GitHub 上的发布者是项目同步账号，正文会注明这是来自公开网站的投稿。

03

申请修改

不用学 Git，也可以提出一个真实的 Pull Request。

请选择要修改的中/英文宪章，粘贴一段现有原文，再给出替换文本。后端会先创建 Issue；只有原文在目标文件中恰好匹配一次时，才自动建立分支和 PR。

04

公开记录

网站只是入口，GitHub 才是公开账本。

这里仅显示最近同步结果。讨论正文、Issue、PR、commit 和最终合并历史都在 GitHub 上公开保留。
