人类共同宪章 · 候选原则 v0.2

状态：开放草案。它不代表任何国家、组织、阶层或“全人类”。

这份文本不是要求他人签署的终稿，而是供公开质疑与修改的起点。

【序言】

人类正在创造越来越强大的人工智能与自动化系统。

如果未来机器能够承担大量思考、劳动、创造与管理，一个长期存在的社会前提可能开始失效：

「人必须通过自己的劳动价值，换取生存资源与社会地位。」

我们不知道 AGI 会在何时、以何种形式出现，也不知道它最终会带来怎样的制度。

因此，这份草案不试图预言唯一未来。它只提出一个更基本的问题：

「即使一个人不再比机器更有经济价值，他是否仍然拥有不应被剥夺的地位？」

【原则一：生存不以经济价值为条件】

任何人都不应仅仅因为无法与机器竞争、无法被市场需要或无法提供足够劳动，而失去维持基本生活与尊严的条件。

需要继续讨论：基本生活条件的边界是什么？这是道德原则、法律权利还是政策目标？如何避免保障制度本身变成控制人的工具？

【原则二：自动化成果应广泛惠及社会】

当人工智能与自动化显著提高社会生产能力时，其收益不应默认无限集中于少数资产所有者。

本原则暂不预设全民分红、公共持股、税收、公共算力或其他具体制度。

【原则三：人保留对文明目标的参与权】

AI 可以提供分析、预测和执行能力，但影响大量人的重大价值目标，不应仅由少数机构或自动系统单方面决定。

需要继续讨论：什么属于重大价值目标？人类是否拥有最终否决权？如果机器方案明显优于人类判断，应如何处理？

【原则四：每个人拥有认知与选择自由】

个人应有权知道自己是否正在受到人工智能系统的重要影响，并有权拒绝未经同意的人格操纵、强制增强或不可退出的算法治理。

需要继续讨论：操纵与正常说服的边界在哪里？儿童、失能者等特殊情形如何处理？是否应保障无 AI 或低 AI 的生活空间？

【原则五：宪章本身必须可以被公众修改】

任何发起人、维护者、专家、企业或 AI 都不应拥有对这份宪章永久且不可挑战的解释权。

草案的形成过程必须留下公开记录，并允许异议、修正与权力退出。

【当前共创方式】

当前阶段故意保持简单：

1. 任何人都可以通过公开网站发起议题；
2. 后端自动把议题同步到 GitHub Discussions；
3. 任何人都可以通过公开网站申请精确文本修改；
4. 后端先创建 GitHub Issue；
5. 当现有原文在目标文件中恰好匹配一次时，后端自动创建分支和 Pull Request；
6. 最终是否合并仍由公开审议决定，不由后端自动合并。

这套机制不是最终治理制度。它只是冷启动阶段用来验证真实参与是否存在的最小基础设施。
